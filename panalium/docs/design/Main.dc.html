Recorrido principal de una Abeja
Entra a la colmena → Explora Panales → Se une a un Enjambre → El Panal se llena y paga → Recibe su Hexakey → Reclama o vende en el Mercado de Abejas
Hexágono como unidad
Avatares, Hexakeys, marcadores de estado y celdas de progreso usan el hexágono. Las tarjetas de contenido siguen siendo rectangulares con radio 16 px para no sacrificar legibilidad.
Carbón + crema
El lienzo es negro carbón; el contenido vive en superficies crema con texto marrón. El amarillo miel se reserva para la acción principal y el progreso.
Progreso = llenado de miel
Cada Panal muestra cuántas celdas están llenas. La barra se rellena de miel de izquierda a derecha y cambia a verde oliva cuando el Panal está completo.
Una acción por pantalla
Cada vista tiene un único botón miel. Todo lo demás es secundario (contorno) o terciario (texto), para que la Abeja siempre sepa cuál es el siguiente paso.
